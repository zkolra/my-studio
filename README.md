# DEV/22 — портфолио (dev22.es)

React + Vite, анимации на GSAP, плавная прокрутка Lenis. Чёрный, лаймовый неон, эффекты кода и терминала.

## Где что менять

- **Все тексты, работы, цены, контакты** — `src/content.js`.
- **Цвета и шрифты** — начало `src/styles/global.css` (`--lime` — фирменный лайм).
- **Видео работ** — `public/reels/<slug>.mp4` и превью `<slug>.jpg`.
  В `content.js` у каждой работы `url` — ссылка на живой сайт (пусто — кнопка «Открыть сайт» не показывается).

## Блоки

| № | Блок | Файл |
|---|---|---|
| 1 | Заставка-терминал: команды печатаются, [OK], логотип вспыхивает неоном | `components/Preloader.jsx` |
| 2 | Первый экран: заголовок, «работают.» расшифровывается; редактор печатает код и «компилируется»; свет за курсором | `components/Hero.jsx` |
| 3 | Бегущая строка технологий `<React />` — быстрее при прокрутке | `components/Stack.jsx` |
| 4 | Работы: карточки складываются стопкой, при наведении сайт прокручивается в превью; клик — окно браузера с прокруткой сайта, закрывается само в конце | `components/Work.jsx`, `components/Player.jsx` |
| 5 | Услуги: свечение за курсором, наклон карточек | `components/Services.jsx` |
| 6 | Процесс как `git log`: ветка прорастает, узлы загораются | `components/Process.jsx` |
| 7 | Контакт: почта копируется по клику, живой терминал (help, services, hire…), огромный DEV/22 | `components/Contact.jsx` |

Шапка: меню «расшифровывается» при наведении, живые часы Испании. Курсор — лаймовый прицел.
