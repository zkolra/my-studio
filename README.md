# DEV/22 — портфолио (dev22.es)

React + Vite, анимации на GSAP, плавная прокрутка Lenis. Чёрный, лаймовый неон, эффекты кода и терминала.

## Где что менять

- **Админка** — [app.pagescms.org](https://app.pagescms.org): вход через GitHub, репозиторий `my-studio`. Настройки админки — файл `.pages.yml`. Каждое сохранение в админке — это коммит, сайт пересобирается сам за 1–2 минуты.
- **Все тексты и цены** — `src/data/ru.json`, `src/data/en.json`, `src/data/es.json` (в админке: «Тексты и цены — RU / EN / ES»). Меняйте фразу во всех трёх языках. Язык выбирается по браузеру посетителя и переключателем в шапке, выбор запоминается.
- **Контакты и работы** — `src/data/site.json` (в админке: «Контакты и работы»). У каждой работы: название, год, цвет, ссылка на живой сайт (`url`, пусто — кнопка «Открыть сайт» не показывается), картинка и тексты на трёх языках.
- **Картинки работ** — `public/images/work/` (в админке: «Медиа → Картинки работ»). По клику живой сайт открывается прямо на странице (iframe).
- **Цвета и шрифты** — начало `src/styles/global.css` (`--lime` — фирменный лайм).
- **Техническое** (код в редакторе на первом экране, заставка-терминал) — `src/content.js`.

## Хостинг

Сборка: `npm run build`, папка `dist`, Node 22 (файл `.node-version`). Подходит Cloudflare Pages (бесплатно, коммерческое использование разрешено) и Vercel.

## Блоки

| № | Блок | Файл |
|---|---|---|
| 1 | Заставка-терминал: команды печатаются, [OK], логотип вспыхивает неоном | `components/Preloader.jsx` |
| 2 | Первый экран: заголовок, «работают.» расшифровывается; редактор печатает код и «компилируется»; свет за курсором | `components/Hero.jsx` |
| 3 | Бегущая строка технологий `<React />` — быстрее при прокрутке | `components/Stack.jsx` |
| 4 | Работы: карточки складываются стопкой, клик — живой сайт открывается прямо здесь в окне браузера, его можно листать и нажимать; можно развернуть на весь экран | `components/Work.jsx`, `components/Player.jsx` |
| 5 | Услуги: свечение за курсором, наклон карточек | `components/Services.jsx` |
| 6 | Процесс как `git log`: ветка прорастает, узлы загораются | `components/Process.jsx` |
| 7 | Контакт: почта копируется по клику, живой терминал (help, services, hire…), огромный DEV/22 | `components/Contact.jsx` |

Шапка: меню «расшифровывается» при наведении, живые часы Испании. Курсор — лаймовый прицел.
